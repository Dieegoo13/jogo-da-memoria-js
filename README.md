<h2 id="sobre">📋 Sobre o Projeto</h2>

O **Jogo da Memória** foi desenvolvido com o objetivo de treinar:

- Manipulação do **DOM**  
- Lógica de programação  
- Geração dinâmica de elementos  
- Animações simples em CSS  
- Estruturação de um mini game totalmente front-end  

O layout é leve e responsivo, e o jogo funciona diretamente no navegador sem necessidade de back-end.

---

<h2 id="funcionalidades">🚀 Funcionalidades Principais</h2>

- 🃏 **Cartas geradas dinamicamente** via JavaScript  
- 🔄 **Sistema de embaralhamento automático**  
- 🎯 **Verificação de pares**  
- 🧩 **Feedback visual de acerto/erro**  
- 🚀 **Botão de reset para reiniciar o jogo**  
- 📱 **Layout responsivo e adaptado para mobile**  
- ⚡ **Aplicação rápida e totalmente front-end**
